# Offline Linux Package Downloader 📦 & GUI 🖥️

ابزار کامل با **محیط گرافیکی (GUI)** و **خط فرمان (CLI)** مبتنی بر Docker برای دانلود پکیج‌های لینوکس (**Ubuntu** و **Debian**) به همراه **تمام وابستگی‌های بازگشتی (Dependencies of Dependencies تا سطح صفر)** و بسته‌بندی در قالب یک فایل **ZIP** به همراه اسکریپت خودکار نصب آفلاین.

---

## ✨ امکانات محیط گرافیکی (GUI)

- 🎨 **رابط کاربری مدرن و واکنش‌گرا**: با پشتیبانی کامل از زبان‌های **فارسی (RTL)** و **انگلیسی (LTR)**
- 🌓 **تم تاریک و روشن (Dark / Light Mode)**
- 🐧 **انتخاب سیستم‌عامل و توزیع هدف**:
  - Ubuntu (`24.04`, `22.04`, `20.04`, `18.04`)
  - Debian (`12`, `11`, `10`)
  - انتخاب معماری (`amd64`, `arm64`, `armhf`, `i386`)
- 🌐 **مدیریت کامل مخازن و میرورها (Repositories)**:
  - انتخاب مخازن و شاخه‌ها: `main`, `universe`, `restricted`, `multiverse` (برای اوبونتو) و `contrib`, `non-free` (برای دبیان)
  - انتخاب سرور دانلود (میرور اختصاصی ایران `ir.archive.ubuntu.com` با سرعت بالا، میرور جهانی، آلمان، آمریکا یا آدرس دلخواه)
  - امکان افزودن مخزن یا PPA اختصاصی
- 🔍 **استعلام خودکار نسخه‌های موجود**: با زدن دکمه «بررسی نسخه‌ها»، لیست تمام نسخه‌های قابل دانلود پکیج از مخازن نمایش داده می‌شود
- 💻 **کنسول زنده لاگ‌ها (Live Terminal Stream)**: مشاهده لحظه‌ای پیشرفت دانلود وابستگی‌ها
- 📁 **مدیریت فایل‌های خروجی**: امکان دانلود مستقیم فایل ZIP از مرورگر، کپی مسیر، حذف و دکمه باز کردن پوشه در فایل‌منیجر اوبونتو (`nautilus`)

## 🚀 نحوه اجرای محیط گرافیکی (GUI)

### روش اول: اجرای مستقیم در اوبونتو (پیشنهادی)

کافیست وارد پوشه برنامه شده و دستور زیر را اجرا کنید:

```bash
cd /home/masoud/.gemini/antigravity/scratch/pkg-downloader
./run-gui.sh
```

این اسکریپت به صورت خودکار سرور محلی را اجرا کرده و مرورگر را باز می‌کند (`http://localhost:5000`).

### روش دوم: از منوی برنامه‌های اوبونتو (Application Menu)

یک شورت‌کات با نام **Offline Package Downloader** (دانلودر پکیج‌های لینوکس) در منوی برنامه‌های سیستم شما قرار داده شده است و می‌توانید با کلیک روی آن، برنامه را باز کنید.

## ⌨️ نحوه استفاده از خط فرمان (CLI)

اگر ترجیح می‌دهید بدون محیط گرافیکی از ترمینال استفاده کنید:

```bash
cd /home/masoud/.gemini/antigravity/scratch/pkg-downloader

# ۱. دانلود با تنظیمات پیش‌فرض (اوبونتو 24.04)
./download.sh -p curl

# ۲. دانلود با مخازن انتخابی (مثلاً main و universe)
./download.sh -p nginx -d ubuntu -r 22.04 -c "main,universe"

# ۳. دانلود برای دبیان 12
./download.sh -p nano -d debian -r 12

# ۴. تعیین نسخه دقیق
./download.sh -p nginx -d ubuntu -r 24.04 -v "1.24.0-2ubuntu7"
```

## 💻 نحوه نصب پکیج روی سیستم مقصد (کامپیوتر آفلاین)

فایل `.zip` دانلود شده را به سیستم آفلاین منتقل کنید:

```bash
# ۱. استخراج فایل زیپ
unzip <package_name>_offline.zip -d offline_pkg

# ۲. ورود به پوشه و اجرای اسکریپت نصب خودکار
cd offline_pkg
sudo bash install.sh
```

اسکریپت `install.sh` تمام فایل‌های `.deb` را با ترتیب صحیح وابستگی‌ها و بدون نیاز به اینترنت نصب و پیکربندی می‌کند.

## 📂 ساختار فایل‌های پروژه

```text
pkg-downloader/
├── app.py                  # سرور پایتون مدیریت REST API و استریم زنده لاگ‌ها
├── run-gui.sh              # اسکریپت راه‌انداز GUI و بازکننده خودکار مرورگر
├── download.sh             # اسکریپت CLI برای استفاده مستقیم از ترمینال
├── entrypoint.sh           # مغز متفکر داخل داکر برای حل بازگشتی وابستگی‌ها
├── Dockerfile              # داکرفایل پارامتریک برای بیلد انواع توزیع‌ها
├── static/
│   ├── index.html          # ساختار صفحه گرافیکی و دوزبانه
│   ├── style.css           # استایل‌های مدرن با تم تاریک/روشن و RTL
│   └── app.js              # منطق جاوااسکریپت، استریم SSE و اتصال به API
└── output/                 # پوشه ذخیره‌سازی بسته‌های ZIP خروجی
```
